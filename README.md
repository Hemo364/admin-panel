# پنل مدیریت (Admin Panel)

یک پنل مدیریت فارسی/راست‌به‌چپ ساخته شده با React 19، Vite و Tailwind CSS v4، به عنوان نمونه‌کار (Portfolio).

## امکانات

- **داشبورد**: کارت‌های آماری واکنش‌گرا و نمودار فروش (Chart.js) با پشتیبانی کامل از حالت تیره
- **مدیریت کاربران**: افزودن، ویرایش، حذف و جستجوی کاربران با اعتبارسنجی فرم
- **مدیریت پست‌ها**: فهرست پست‌ها با جستجو، وضعیت انتشار و حذف
- **مدیریت کامنت‌ها**: تأیید/اسپم/حذف کامنت‌ها با فیلتر بر اساس وضعیت
- **مدیریت تسک‌ها**: افزودن تسک، تعیین اولویت، علامت‌گذاری انجام‌شده و فیلتر
- **مدیریت دسته‌بندی محصولات**: افزودن، ویرایش، حذف، جستجو و صفحه‌بندی
- **حالت تیره/روشن** با ذخیره‌سازی در `localStorage`
- **کاملاً واکنش‌گرا** (موبایل، تبلت، دسکتاپ) با نوار کناری کشویی در موبایل
- تمام داده‌ها به صورت محلی در `localStorage` ذخیره می‌شوند (بدون نیاز به بک‌اند)

## تکنولوژی‌ها

React 19 · React Router 7 · Tailwind CSS v4 · Chart.js · Moment Jalaali · React Icons

## اجرای پروژه

```bash
npm install
npm run dev
```
